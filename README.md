# CB Shows Landing

Landing page da CB Shows construída com Astro para captação de leads de shows, produção executiva e logística.

## Rodando localmente

```sh
npm install
npm run dev
```

## Build de produção

```sh
npm run build
```

## Deploy

O deploy está configurado para GitHub Pages via GitHub Actions.

- Repositório esperado: `rafaelroriz-age/cb-shows-landing`
- URL publicada: `https://cb-shows.com.br/`

Cada push na branch `main` dispara a publicação.
